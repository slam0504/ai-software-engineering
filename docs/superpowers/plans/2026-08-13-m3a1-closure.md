## Global Constraints

- **Fail closed**：所有新驗證（bump token、CAS、preflight、role 完整性）失敗路徑一律拒絕＋錯誤原文；不靜默降級。
- **Accept-before-write**：bump 只改 editor buffer，不寫檔、不 commit；使用者仍走「儲存→預覽 commit→建立 commit→重新送核」。
- **權威在後端**：digest 一律後端自算（§3.2）；`gate2_approval_id` 由後端在 workflowMu 下擷取固定，前端值僅作 CAS（§3.3.2）。
- **契約 additive**：workspace event 只加欄位（`gate2_approval_id`）；`RunEvidence` 簽名擴充需同 commit 更新 wailsjs＋前端呼叫點（可執行基線）。
- **導航只改 view**：STALE 引導不得自動改檔案、解 blocker、重送核（§3.5.3）。
- **誤分類禁止**：preflight 失敗＝enforcement-unproven；preflight 通過後的啟動失敗／模型錯誤／逾時走一般錯誤路徑（§3.4.4）。
- **i18n**：新 UI 字串進 zh-TW＋en 雙 locale，key parity 測試綠；台灣慣用語；契約值（gate 名、role、OID、digest）維持原文。
- **收尾 gate**：`go vet ./...`／`go test -race ./... -count=1`／`npm --prefix frontend run test`／`npm --prefix frontend run build`／`wails build`。
